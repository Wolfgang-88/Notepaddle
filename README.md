# Notepaddle

**English** | [Deutsch](#deutsch)

---

## English

Notepaddle is a simple dark-mode text editor for Windows.

### Features

- **Dark theme**
- **Syntax highlighting for Python**
- **Autocomplete for Python** 
- **Markdown viewer** 
- **Line numbers**, optional
- **Remembers your settings**

### Keyboard shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+N` / `Ctrl+O` | New / Open |
| `Ctrl+S` / `Ctrl+Shift+S` | Save / Save as |
| `Ctrl+Q` | Quit |
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+A` | Select all |
| `Ctrl+F` / `Ctrl+H` | Find / Replace |
| `F3` / `Shift+F3` | Next / previous match |
| `Ctrl+Space` | Show autocomplete suggestions |
| `Ctrl+Shift+V` | Toggle Markdown viewer (`.md` files) |
| `Ctrl+Plus` / `Ctrl+Minus` / `Ctrl+Wheel` | Zoom in / out |

### Files

| File | Purpose |
|---|---|
| `Notepaddle.py` | The program |
| `Notepaddle.ico` | Window icon |
| `Notepaddle.json` | Settings, created automatically |

## Deutsch

Notepaddle ist ein schlichter Texteditor im Dark Mode für Windows.

### Funktionen

- **Dunkles Design**
- **Syntaxhervorhebung für Python** 
- **Autovervollständigung für Python**
- **Markdown-Viewer**
- **Suchen & Ersetzen**
- **Zeilennummern**, optional
- **Merkt sich die Einstellungen**

### Tastenkürzel

| Kürzel | Aktion |
|---|---|
| `Strg+N` / `Strg+O` | Neu / Öffnen |
| `Strg+S` / `Strg+Umschalt+S` | Speichern / Speichern unter |
| `Strg+Q` | Beenden |
| `Strg+Z` / `Strg+Y` | Rückgängig / Wiederholen |
| `Strg+A` | Alles auswählen |
| `Strg+F` / `Strg+H` | Suchen / Ersetzen |
| `F3` / `Umschalt+F3` | Nächster / vorheriger Treffer |
| `Strg+Leertaste` | Vorschläge der Autovervollständigung |
| `Strg+Umschalt+V` | Markdown-Viewer umschalten (`.md`-Dateien) |
| `Strg+Plus` / `Strg+Minus` / `Strg+Mausrad` | Schrift größer / kleiner |

### Dateien

| Datei | Zweck |
|---|---|
| `Notepaddle.py` | Das Programm |
| `Notepaddle.ico` | Fenster-Icon |
| `Notepaddle.json` | Einstellungen, wird automatisch angelegt |
